# Bio-Inspired Swarm Navigation on Resource

This repository contains the source code for the "Bio-Inspired Swarm Navigation on Resource" project.

## Project Structure

- `src/`: Source code for ROS packages.
- `simulation_results/`: Results from simulations (ignored in git).
- `process_results.py`: Script for processing simulation data.
- `ros_diag.py`: ROS diagnostics script.
- `verify_logic.py`: Logic verification script.

## Setup and Installation

This is a ROS workspace. To build the project:

```bash
cd formicabot_ws
colcon build
source install/setup.bash
```
